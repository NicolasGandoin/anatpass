🎯 Contrôle strict des réponses (Concours PASS) :

Pour éviter d'apprendre des termes non conformes aux grilles d'évaluation du concours, le Mode Strict PASS n'accepte que la dénomination officielle du cours. Si vous tapez un synonyme ou une ancienne nomenclature (ex: cubitus pour ulna, rotule pour patella, os iliaque pour os coxal), l'application vous signale l'erreur et vous affiche la vraie réponse officielle à mémoriser.

Les termes anatomiquement faux (comme bassin pour désigner l'os coxal, ou ventre pour l'abdomen) sont systématiquement refusés.
